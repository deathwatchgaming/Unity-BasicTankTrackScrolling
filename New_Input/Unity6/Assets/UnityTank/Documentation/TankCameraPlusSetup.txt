---------------------------------
UnityTank Tank Camera Plus: Setup |
---------------------------------


Description: A simple enhanced camera script for "UnityTank" and steps to add / setup such.

This camera script provides a dual-mode camera (Follow + Orbit) with robust anti-clipping, mode transition safety, 
and full support for both cursor locked and unlocked states.

Keyboard: C key to switch camera mode
Mouse: for movement / rotation

Note: If you were previously using The "TankCamera.cs" script, you can either disable or remove that component and use this "TankCameraPlus.cs" script instead if you desire using such for a more enhanced camera experience.

If using this "TankCameraPlus.cs" script instead....


----------
Step: 1) |
----------


Create > "Empty" > "GameObject" in "Tank" object.


Transform: 
----------

Set: (For Example)

X: 0  Y: 0  Z: 0
X: 0  Y: 0  Z: 0 
X: 1  Y: 1  Z: 1 


Rename > "Empty" > "GameObject" to "Tank Camera Root" for now, for example, else something you desire later.

Suggested: If desired, you could rename to > "Tank Camera" just for example.


----------
Step: 2) |
----------


In >  "Tank Camera Root" > create a camera: "Camera"

Set tag as: "MainCamera"


Transform: 
----------

Set: (For Example)

X: 0  Y: 0.32  Z: -6.2 
X: 0  Y: 0  Z: 0 
X: 1  Y: 1  Z: 1 


Rename > "Camera" > to "Tank Camera" for now, for example, else something you desire later.

Suggested: If desired, you could rename to > "Tank Cam" just for example.


----------
Step: 3) |
----------


Add Script > "TankCameraPlus.cs" to "Tank Camera Root" holder.*


Set resources: ("For Example")*
-------------------------------

Tank Rigidbody: Tank (Rigidbody)
Tank Transform: Tank (Transform)
Camera Root: Tank Camera Root(Transform)
Camera Transform: Tank Camera (Transform)


Else, Suggested: If desired, you could rename as below:


Set resources: ("For Example")*
-------------------------------

Tank Rigidbody: Tank (Rigidbody)
Tank Transform: Tank (Transform)
Camera Root: Tank Camera (Transform)
Camera Transform: Tank Cam (Transform)


Set the input actions asset:
----------------------------

Input Actions: TankCamPlusInputActions (Input Action Asset)


Settings: (Default - Tweak such to your needs) 
----------------------------------------------

Rotation Threshold: 1
Rotation Speed: 5
Distance: 10
Height: 2
Rotation Damping: 3
Height Damping: 2
......
.......


That is it! Tweak such to your likings and enjoy!


Tip: you can also then perhaps opt to make the "Camera Root" a prefab
and would do such firstly before then say opting to make "Tank" object a prefab ie:"Tank".
